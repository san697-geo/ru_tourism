# Анализ туристских потоков России

Анализ въездного и выездного туристского потока России, а также анализ туристских потоков по данным Росстата.

## Данные

Источник: Росстат (URL: https://rosstat.gov.ru/statistics/turizm), раздел "Туризм".

В репозитория используются очищенные CSV-файлы:
- 'data/modified_data/Poezdki/flow_all.csv' - общий въездной/выездно поток по годам (2014-2025);
- 'data/modified_data/Poezdki/2025_russian_to_country_1' - выезд по странам за 2025 год;
- 'data/modified_data/Poezdki/2025_country_flow_1' - въезд по странам за 2025 год;
- 'data/modified_data/Turpotok/2025_tour_flow_regions' - туристский поток по регионам России за 2025 год.

## Что сделано?

В Jupyter Notebook построены 5 визуализаций (*графиков*):

1. **Динамика въездного и выездного потока (2014-2025)** - линейный график.
2. **Соотношение въезда и выезда по годам** - столбчатая диаграмма.
3. **Топ-10 стран по въезду в России (2025)** - горизонтальная столбчатая диаграмма.
4. **Топ-10 стран, куда уезжают россияне (2025)** - горизонтальная столбчатая диаграмма.
5. **Топ-10 регионов России по туристсокому потоку** - горизонтальная столбчатая диаграмма.

## Выводы
- Выезд россиян стабильно превышает въезд; после ковида выезд восстановился быстрее.
- Въезд: лидируют страны СНГ и Китай (*работа, учёба, частные визиты*).
- Выезд: курорты (*Турция, ОАЭ, Египет, Таиланд*) и страны СНГ.
- Внутри России: Московская агломерация, курорты (*Краснодарский край, Крым*), крупные промышленные центры.
